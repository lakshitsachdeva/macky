# Code of Conduct

## Our standard

We want Custody to be a rigorous, welcoming project for security researchers, defenders, developers, and learners. Participants should communicate respectfully, assume good faith, and focus criticism on evidence and implementation rather than people.

## Expected behavior

- Be respectful and technically specific.
- Protect private evidence, credentials, and personal information.
- Explain uncertainty and limitations.
- Welcome corrections supported by reproducible evidence.
- Keep discussions relevant to the project.

## Unacceptable behavior

- harassment, threats, discrimination, or personal attacks;
- publishing private evidence or credentials;
- doxxing or targeted abuse;
- deliberately misleading forensic or security claims;
- malicious code or test fixtures disguised as evidence;
- disruptive spam or repeated bad-faith interaction.

## Enforcement

Report conduct concerns privately to the maintainer through the repository’s available GitHub contact channel. Reports will be reviewed as reasonably as possible for an experimental project.
